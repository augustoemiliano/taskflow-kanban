# TaskFlow Kanban — Front-end

SPA em React + TypeScript + Vite. A documentação completa (como rodar, arquitetura, endpoints) está no [README da raiz](../README.md).

```bash
cp .env.example .env   # VITE_API_URL=http://localhost:3333/api
npm install
npm run dev            # http://localhost:5173
npm test               # Vitest + Testing Library
npm run lint
npm run build
```
